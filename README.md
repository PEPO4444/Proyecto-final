# Bot del cambio climático

Es un bot el cual cada 30 segundos envía un dato sobre el cambio climático.

Se puede usar para concientizar sobre el cambio climático

Como usarlo:
$iniciar
Empieza el bucle de enviado de datos

$detener 
deja de enviar datos
